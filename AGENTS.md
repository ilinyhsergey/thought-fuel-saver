# Project instructions
## Setup Install dependencies:
npm install
## Commands Run tests:
npm test 
## Run linter:
npm run lint
## Code rules
- Use TypeScript.
- Do not use `any`.
- Follow the existing project structure.
- Do not modify files in `.idea/` and `node_modules/`.
## Before finishing Run tests and lint.
